# Week 1: Demonstration of fork() System Call

## Aim
To study and demonstrate process creation using the fork()
system call in Unix/Linux.

## Problem Statement
Write a C program to demonstrate the fork() system call.
Display the process IDs of the parent and child processes
and observe how both processes execute after fork().

## Concepts Used
- fork()
- getpid()
- getppid()
- Parent and child processes
