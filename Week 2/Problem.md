# Week 2: Sum of Odd and Even Numbers Using fork()

## Aim
To demonstrate independent execution of parent and child
processes using fork().

## Problem Statement
Write a C program in which the parent process calculates
the sum of odd numbers and the child process calculates
the sum of even numbers from an array using fork().

## Concepts Used
- fork()
- Arrays
- Parent and child processes
- Conditional statements
- wait()
