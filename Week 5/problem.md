# Week 5: Implementation of Pipe

## Aim
To implement inter-process communication using an unnamed pipe.

## Problem Statement
Write a C program to demonstrate communication between
a parent and child process using an unnamed pipe.
The child process writes a message to the pipe, and
the parent process reads and displays the message.

## Concepts Used
- pipe()
- fork()
- read()
- write()
- close()
- Inter-process communication (IPC)
